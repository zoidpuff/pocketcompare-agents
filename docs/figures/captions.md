# Figure captions

All figures are generated by `make_figures.py <research-repo>` (PNG at 200 dpi + SVG). Every plotted number is read
from the files listed under each caption, which are paths in the research repository. No file under `data/sealed/`
is opened.

## fig1_pipeline — How a pocket becomes a fingerprint
BURROW first places a 1 Å grid of feature-annotated points on the structure; ligands, waters and ions are removed
first. A site is located in one of two ways: in deployment it is a pocket BURROW detects; in benchmarks it is the
detected pocket that covers the known ligand. The site is then redrawn as all buried points within 8 Å of its buried
centre ("sph8"), so the same object results however the site was found. A 514-number typed cavity fingerprint and a
113-number protein-environment block (627 numbers) are projected by three learned linear maps into one 384-number unit
vector, and two pockets are compared with a dot product (cosine). FAISS indexes the vectors for search.
Sources: `configs/final_method.yaml` (dimensions, sph8 radius, buriedness cut-off, seeds); `reports/a1_descriptors.md`
(A1 block sizes); `results/dev/final_method_runtime.json` (ms per pocket, head µs, µs per pair, bytes);
`results/tooling/describe_runtime.json` (s per structure).

## fig2_data — Evaluation data and how they were protected
(A) On TOUGH-M1, pockets homologous to BURROW's training proteins became the development set. Pockets with no such
homologue became the sealed test set. Pockets homologous both to BURROW training and to another sealed test set
(76 %) were excluded. (B) PDB-T is a temporal test set built after the main test was spent: PDB entries released
after the BioLiP snapshot behind every training set, with all proteins homologous to any training source removed.
(C) The role of each dataset; locked cells were sealed (unreadable files with recorded checksums) and read once by
the frozen method.
Sources: `data/splits/tough_m1_split_counts.json`, `data/splits/blips_split_counts_v2.json`,
`data/splits/blips_split_counts.json` (BLiPS test), `data/splits/ppips_burrow_homology.json`,
`data/processed/pdbt/enumerate_counts.json`, `data/processed/pdbt/sites_counts.json`, `results/pdbt/build_counts.json`,

## fig3_ligand_imprint — Ligand-defined pockets carry the ligand's size
(A) Schematic. A ligand-defined pocket (all grid points within 4 Å of the bound ligand) copies the ligand's size and
shape; a detected pocket does not depend on the ligand. (B) TOUGH-M1 test ROC-AUC for the same methods with
ligand-defined (L; all 24,337 pairs) and detected (D; the 21,410 pairs where both pockets were detected) pockets. The
raw-site fingerprint A1 falls to chance without the ligand. pocketcompare scores the same in both modes because it
redraws every site (sph8). (C) Scores that use only a size difference: ligand heavy-atom count alone reaches 0.95,
and the volume of the 4 Å ligand shell 0.80. Volumes of detected pockets, or of TOUGH-M1's own fpocket pockets, stay
near chance (0.48–0.56).
Sources: `results/final/final_summary.parquet` (B); `results/verify/v_tough.json` (C; independent verifier).

## fig4_claims — Pre-registered claims
Effect sizes are differences in ROC-AUC with 95 % bootstrap confidence intervals, shown for the four claims of the
main test and the three claims of the temporal replication (PDB-T). The dashed line marks the smallest effect of
interest (0.03). C1-D (detected pockets) is the robust headline and replicates on fresh data (R1). C1a/C1b pass Holm
correction in the pre-registered run but are Monte-Carlo fragile: the verifier's independent 2,000-replicate re-runs
give p values on both sides of the 0.0167 threshold. C2, R2 and R3 are not supported.
Sources: `results/final/final_claims.json`, `results/pdbt/claims.json`, `results/verify/v_tough_mc_C1a.json`,
`results/verify/v_tough_mc_C1b.json`, `results/final/unseal_log.tsv` (time the test was opened);
`reports/verification_final.md`.

## fig5_tough_comparison — Raw vs size-stratified AUC on TOUGH-M1 test
Open orange circles show the raw ROC-AUC. Filled blue circles show the AUC computed within 5 × 20 bins of similar
pocket size, which removes the size shortcut. Pocket size alone drops from 0.80 to 0.50, and the published tools
(G-LoSA, SiteEngine, APoc; scores shipped with TOUGH-M1, computed on their own pockets) and the raw-site fingerprint
A1 also lose AUC. pocketcompare rises slightly (0.70 → 0.72). There are no paired CIs for the published tools, so
treat these as point comparisons. APoc is the better of its two shipped columns (−log p), and L4 is its declared
(CSLS) variant.
Source: `results/final/final_summary.parquet` (set tough_m1_test, mode L or native).

## fig6_robustness — AlphaFold models, detection cut-offs, blind search
(A) Paired change in ROC-AUC from AlphaFold models to crystal structures on the same BLiPS-test pairs. All CIs for
pocketcompare lie inside ±0.03; this item was computed post hoc with the frozen code (DEV6). (B) Raising the minimum
BURROW pocket score removes many pockets but few true ligand sites, measured as the fraction of detected sites kept
(development data). (C) Blind search on AlphaFold models: each site's ligand-sharing partner is ranked against all
~14,000 detected pockets. The blue estimates count only partners that BURROW detected; the gray estimates count
missed detections as failures.
Sources: `results/final_post/c5_holo_minus_af.parquet` (A, stratum "all"); `results/tooling/site_score_recall.json`
(B); `results/final_post/blind_test/metrics.csv` (C).

## fig9_process — The agentic process as a timeline
Each marker is a recorded decision (D…), disclosed deviation (DEV…) or logged event, placed by its time in five
activity lanes. Vertical gray lines mark the milestone summaries M0–M4, and the blue line marks the method freeze;
sealed test files were first read after it. Times come from RESEARCH_TREE.md, where some are approximate (written by
hand, and early entries differ from git commit times by up to ~50 min). Event times come from the unseal logs, the
PDB-T gate file and the git commit of docs/AFDB_COST.md. Markers within ~7 min of each other in a lane are nudged
apart slightly.
Sources: `RESEARCH_TREE.md` (Decisions, status headings), `results/final/unseal_log.tsv`, `results/verify/unseal_log.tsv`,
`results/pdbt/gate.json` (created), `results/pdbt/unseal_log.tsv`, `git log -- docs/AFDB_COST.md`.

## fig8_negative — What did not work
(A) Pre-registered ideas that gave no improvement. Adding fragment-docking profiles to the cavity fingerprint failed
its gate, which required +0.01 in size-stratified AUC. Fragments did not beat lead-like molecules for PPI pockets in
any of the three profile types. On fresh PDB-T data, neither score fusion with L4 nor L4 alone beat pocketcompare.
Units differ by row (ΔAUC or ΔMRR); 0 means no improvement. (B) In the exploratory PPI-R test, PPI-inhibitor pockets
were not recognised across homology groups against size- and buriedness-matched ligand pockets: all AUCs are near 0.5.
Sources: `results/dev/tough_m1_dev_v2splits_details.json` (gate A1+A2frag|raw, delta_strat_vs_cf_A1),
`results/dev/ppips_val_v2splits_details.json` (hypothesis, stratum all, raw), `results/pdbt/claims.json` (R2, R3),
`results/exploratory/ppi_r/summary.json` (query-mean AUC).
